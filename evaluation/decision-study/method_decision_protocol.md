# Secondary test of a typed decision as a reranker

Specified after the main five-arm study and before scoring any new Laya outputs. Reuse all 26 official ACL-ARC test Uses contexts and all nine previously inspected CSFCube method tasks. Candidate generation, canonical IDs, years and query text are fixed by the main study. Restrict this exploratory comparison to the two tasks with an observed cited source or graded relevance. Laya receives each of the same first 20 fusion candidates as the cross-encoder. It receives the query text and candidate text only. Order by the numeric response to the existing technical-match question from decision_features.py, retaining fusion order for ties. No calibration, fitted weights, gold name, thresholds or prompt sweep. Report hit queries and useful slots in top three, paired cluster bootstrap versus fusion, and record model outputs for audit. This checkpoint is the open Laya typed-decision model, evaluated separately from the proprietary Jev service.
